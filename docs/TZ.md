# Техническое задание: Instagram (учебная копия)

> **Статус:** черновик v0.1 · **Дата:** 21.10.2026 · **Срок сдачи:** суббота, 24.10.2026, вечер
> **Команда:** 2 человека + Claude Code

Этот документ отвечает на вопрос **«ЧТО мы делаем»**. Как это устроено технически, описано в [`spec/`](./spec/README.md). Когда и в каком порядке, описано в [`ROADMAP.md`](./ROADMAP.md).

---

## 1. Цель проекта

Сделать веб-приложение, которое повторяет основные функции Instagram: публикации, ленту, Stories, Reels, директ, аудио- и видеозвонки (в том числе групповые), уведомления в реальном времени.

Учебные цели:
- научиться работать в монорепозитории командой из двух человек через Git и GitHub;
- научиться разрабатывать с помощью AI (Claude Code) по заранее написанной документации;
- пройти полный цикл: ТЗ → спецификация → разработка → деплой.

## 2. Платформа

- Веб-приложение, открывается в браузере.
- **Desktop-first:** основной вид — десктоп (ноутбук), на нём проект проверяется. Мобильная версия — адаптация десктопной, тоже должна выглядеть аккуратно.
- **Языки интерфейса: английский (основной) и русский.** По умолчанию английский, русский включается в настройках. Документация проекта — на русском.
- Поддерживаемые браузеры: последние версии Chrome, Edge, Firefox, Safari. Push-уведомления проверяем в Chrome.

## 3. Роли пользователей

| Роль | Описание |
|---|---|
| Гость | Не авторизован. Видит только страницы входа и регистрации. |
| Пользователь | Авторизован. Доступны все функции. |
| Администратор | Обычный пользователь с флагом `role = ADMIN`. Дополнительно видит админ-панель (`ADMIN-*`). Назначается только через seed или базу, из интерфейса не выдаётся. |

| Код | Требование | Приоритет |
|---|---|---|
| LIVE-1 | Начать прямой эфир (кнопка в меню создания); у пользователя может быть только один активный эфир | P2 |
| LIVE-2 | Подписчики получают уведомление и push «user начал(а) прямой эфир» | P2 |
| LIVE-3 | Аватар ведущего в панели Stories с красным кольцом и меткой «LIVE»; клик открывает эфир | P2 |
| LIVE-4 | Экран зрителя: видео на весь экран, имя ведущего, счётчик зрителей | P2 |
| LIVE-5 | Чат эфира в реальном времени и «сердечки» поверх видео | P2 |
| LIVE-6 | Ведущий завершает эфир; эфир завершается сам, если ведущий отключился больше чем на 60 секунд; зрители видят «Эфир завершён» | P2 |

**Не делаем:** запись и повтор эфира, совместный эфир с гостем, донаты.

## 6. Что НЕ входит в проект

- Подтверждение email, восстановление пароля, 2FA
- Автоматическая модерация (фильтры, ИИ-проверка контента); жалобы и админ-панель — только в объёме `ADMIN-*`
- Реклама, магазин, бизнес-аккаунты, статистика для авторов
- Запись и повтор прямых эфиров, эфир с гостем
- Музыка в Reels/Stories, фильтры и редактор видео
- Мобильные приложения (только веб) и нативные push для них
- Другие языки, кроме английского и русского; перевод пользовательского контента (подписей, сообщений)
- Удаление аккаунта, скачивание своих данных

## 7. Критерии приёмки

Проект считается сданным, если:
1. Все требования **P0** работают.
2. Два пользователя на двух разных браузерах могут: подписаться друг на друга, увидеть посты друг друга в ленте, лайкнуть и прокомментировать, посмотреть Stories, переписываться в реальном времени, созвониться по видео. При закрытой вкладке получателю приходит push о сообщении и о звонке.
3. Три и более пользователей могут провести групповой видеозвонок из группового чата.
4. Проект запускается по инструкции из `README.md`.
5. Код лежит в GitHub, работа велась через ветки и Pull Request.
