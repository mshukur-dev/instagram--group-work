# Спецификация

Спецификация отвечает на вопрос **«КАК это устроено технически»**. Что именно делаем, описано в [`../TZ.md`](../TZ.md).

Спек разбит на файлы, чтобы человек или AI читали только то, что нужно для текущей задачи.

| Файл | О чём | Читать, когда… |
|---|---|---|
| [architecture.md](./architecture.md) | Общая схема системы, стек, структура монорепо, почему выбрано именно так | первый раз знакомишься с проектом |
| [backend.md](./backend.md) | Правила NestJS: модули, DTO, ошибки, пагинация, доступ к данным | пишешь что-то в `apps/api` |
| [frontend.md](./frontend.md) | Правила Next.js: роуты, Axios, TanStack Query, Zustand, компоненты | пишешь что-то в `apps/web` |
| [auth.md](./auth.md) | Регистрация, вход, Google, JWT, cookies, refresh | трогаешь авторизацию или защищённые роуты |
| [database.md](./database.md) | Все таблицы и связи (Prisma-схема) с пояснениями | добавляешь фичу, которая хранит данные |
| [api.md](./api.md) | Все REST-эндпоинты | пишешь эндпоинт или вызываешь его с фронта |
| [realtime.md](./realtime.md) | Socket.IO: события директа, уведомлений, звонков | работаешь с директом, уведомлениями, онлайн-статусом |
| [calls.md](./calls.md) | Звонки через LiveKit: 1 на 1 и групповые | работаешь со звонками |
| [i18n.md](./i18n.md) | Два языка: английский и русский, файлы переводов, ошибки, даты | пишешь любой текст в интерфейсе |
| [push.md](./push.md) | Push-уведомления в браузере (Web Push, Service Worker) | работаешь с уведомлениями о сообщениях, звонках, лайках |
| [media.md](./media.md) | Загрузка фото и видео в Cloudinary | загружаешь или показываешь медиа |

**Правило:** если в коде появилось решение, которое расходится со спеком, — сначала обнови спек, потом код. Спек всегда должен описывать реальное состояние проекта.
