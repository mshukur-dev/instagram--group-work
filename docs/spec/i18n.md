# Языки (i18n)

Требования: `SETTINGS-10`, `NFR-10` в [TZ.md](../TZ.md).

## 1. Решения

| Вопрос | Решение |
|---|---|
| Языки | `en` (основной, по умолчанию) и `ru` |
| Библиотека | `next-intl` |
| Язык в URL | **Нет** (`/explore`, а не `/en/explore`) — как в настоящем Instagram |
| Где хранится выбор | В аккаунте (`User.language`) + cookie `NEXT_LOCALE` |
| Где переключается | Настройки → Language. Другие места (например, низ страницы входа) решим позже |
| Что переводится | Весь интерфейс, ошибки, уведомления, push, даты и числа |
| Что НЕ переводится | Контент пользователей: подписи, комментарии, сообщения, имена |

## 2. Как определяется язык

```
1. Есть cookie NEXT_LOCALE → используем её
2. Нет → en
```

- После входа фронт получает `Me.language` и, если он отличается от cookie, обновляет cookie и перерисовывает страницу. Так язык одинаковый на всех устройствах пользователя.
- Смена языка в настройках: `PATCH /settings { language: 'RU' }` → обновить cookie → `router.refresh()`.
- Неавторизованный пользователь (страницы входа и регистрации) видит английский, пока не выбрал другой язык.

## 3. Фронтенд

### Файлы переводов

```
apps/web/messages/
├── en.json      основной: все ключи обязаны быть здесь
└── ru.json      те же ключи на русском
```

Ключи группируются по фичам:

```json
{
  "common": { "follow": "Follow", "following": "Following", "message": "Message", "cancel": "Cancel" },
  "auth":   { "logIn": "Log in", "signUp": "Sign up", "orContinueWith": "OR" },
  "feed":   { "empty": "No posts yet", "suggestedForYou": "Suggested for you" },
  "post":   { "likes": "{count, plural, one {# like} other {# likes}}" },
  "errors": { "USERNAME_TAKEN": "This username isn't available.", "UNKNOWN": "Something went wrong." }
}
```

```json
{
  "post": { "likes": "{count, plural, one {# отметка «Нравится»} few {# отметки «Нравится»} many {# отметок «Нравится»} other {# отметки «Нравится»}}" }
}
```

Русский язык требует форм `one / few / many` (1 отметка, 2 отметки, 5 отметок). `next-intl` поддерживает это через ICU-синтаксис.

### Использование

```tsx
const t = useTranslations('feed');
return <p>{t('empty')}</p>;
```

### Правила

1. **Ни одной строки текста прямо в компоненте.** Только `t('...')`. Это касается кнопок, placeholder, `aria-label`, `alt`, тостов.
2. Новый ключ добавляется **сразу в оба файла** — `en.json` и `ru.json`. AI делает это автоматически по правилу из `CLAUDE.md`.
3. Даты: `date-fns` с локалью (`en-US` / `ru`). Короткий формат как в Instagram: `2h` / `2 ч`, `3d` / `3 дн.`.
4. Числа: `Intl.NumberFormat` — `1.2M` / `1,2 млн`.
5. Проверка: скрипт `pnpm --filter web i18n:check` сравнивает ключи в `en.json` и `ru.json` и падает, если чего-то не хватает. Запускается в CI.

## 4. Бэкенд

### Ошибки: код + английский текст

API возвращает **код ошибки**, а фронт переводит его:

```json
{ "statusCode": 409, "code": "USERNAME_TAKEN", "message": "This username isn't available." }
```

```ts
// apps/web: show error
t(`errors.${error.code}`)   // falls back to errors.UNKNOWN
```

Коды ошибок — enum `ErrorCode` в `packages/shared/src/constants/error-codes.ts`. Ошибки валидации zod тоже переводятся на фронте (react-hook-form показывает свои сообщения по ключам).

### Уведомления и системные сообщения

API **не хранит готовый текст** уведомлений и системных сообщений в чате. Хранится тип и данные (`type: 'POST_LIKE', actorId, postId`), а текст собирает фронт на языке того, кто смотрит. Поэтому смена языка сразу меняет и старые уведомления.

### Push-уведомления

Push показывается без участия нашего фронта, поэтому текст собирает **бэкенд** на языке получателя (`User.language`). Небольшой словарь шаблонов лежит в `apps/api/src/modules/push/push-messages.ts`:

```ts
export const pushMessages = {
  EN: { POST_LIKE: (actor: string) => `${actor} liked your post.`, CALL: (actor: string) => `${actor} is calling you…` },
  RU: { POST_LIKE: (actor: string) => `${actor} нравится ваша публикация.`, CALL: (actor: string) => `${actor} звонит вам…` },
};
```
