# Демо-мир: большая заливка и боты

Чтобы сайт на показе выглядел живым: много людей и публикаций (заливка) и аккаунты, которые сами что-то делают (боты).

## 1. Медиа (`apps/api/prisma/media/`)

Фото и видео — с **Pixabay** (бесплатная лицензия Pixabay Content License), скопированы в наш Cloudinary (`instagram/seed/posts|reels|stories`), а не берутся по ссылкам с Pixabay.

| Файл           | Что делает                                                                                                                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `topics.ts`    | 20 тем (собаки, коты, еда, путешествия, город, спорт, скейт, искусство, музыка, мода, природа, море, небо, машины, друзья, техника, люди…): поисковые запросы, сколько брать, теги-фильтры |
| `collect.ts`   | ищет по темам: только настоящая съёмка (`video_type=film`), видео 5–30 с, без тегов «AI / cartoon / abstract», без откровенного и без детей; пишет `manifest.json`                         |
| `upload.ts`    | Cloudinary сам скачивает каждый файл с Pixabay; результат — `library.json` (адреса в нашем Cloudinary). Повторный запуск докачивает недостающее                                            |
| `library.json` | **в репозитории**: заливка читает его, Pixabay и ключ для неё больше не нужны                                                                                                              |

После `collect.ts` превью проверены вручную, неудачные удалены из `manifest.json`. Итог: 134 видео, 805 фото, 123 вертикальных кадра для историй.

Пересобрать медиа (нужен `PIXABAY_API_KEY` в `apps/api/.env`):

```bash
cd apps/api
node --env-file=.env -r ts-node/register/transpile-only prisma/media/collect.ts
node --env-file=.env -r ts-node/register/transpile-only prisma/media/upload.ts
```

## 2. Заливка (`prisma/seed.ts`, тексты в `prisma/seed-data.ts`)

`pnpm --filter api db:seed` — **стирает базу** и создаёт (~40 с локально):

- **300 человек**, пароль у всех `password123`:
  - 10 прежних тестовых аккаунтов (`alex.morgan` — админ, `emma.design` — закрытый);
  - 24 больших тематических аккаунта (`barkley.the.pup`, `mr.whiskers.daily`, `chef.marco.v`, `nomad.lena`…) — к реальному числу подписчиков прибавлена «внешняя» аудитория (8 тыс. – 900 тыс.);
  - ~266 обычных людей (русские и английские имена, аватарки randomuser/pravatar).
- **~1300 фото-постов и ~280 Reels** по темам автора, подписи на языке автора (смешные и обычные), хэштеги, места, отметки друзей.
- **~110 тыс. лайков, ~14 тыс. комментариев** (с ответами автора и лайками комментариев), сохранения.
- **Истории** за последние 20 часов (живут 24 часа — заливать в день показа или включить ботов, они публикуют новые), просмотры и лайки историй, актуальные (highlights).
- **Чаты** у 10 тестовых аккаунтов (личные и группы, репосты Reels, реакции, непрочитанные), **уведомления** из всего этого.

Случайность с фиксированным зерном: каждый запуск даёт один и тот же мир. Демо-аккаунты отличаются почтой `…@bot.instagram.test`.

## 3. Боты (`apps/api/src/modules/demo/`)

Включаются переменной **`DEMO_BOTS=true`** (по умолчанию выключены). Действуют через обычные сервисы, поэтому уведомления, сокеты и push срабатывают как от живых людей.

- **Каждые ~9 с** с одним из реальных людей, кто сейчас онлайн (не чаще раза в 45 с на человека): лайк его поста, комментарий, подписка, лайк истории, изредка первое сообщение (не чаще раза в 20 минут на человека).
- **Фон** (даже когда никого нет): демо-аккаунты лайкают свежие посты друг друга и выкладывают новые истории из своих старых кадров — лента историй не пустеет.
- **Ответы в директе**: на сообщение демо-аккаунту — «прочитано», «печатает…» и ответ по смыслу (`demo-lines.ts`: приветствие, «как дела», спасибо, смех, встреча, вопрос…) на языке сообщения. В группах отвечают не на каждое сообщение.

Бесплатный Render засыпает через 15 минут без запросов, и боты спят вместе с ним: перед показом нужен пинг `/api/health` (см. [deploy.md](../deploy.md)).
