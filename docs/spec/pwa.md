# PWA — сайт как приложение

Сайт устанавливается на телефон и компьютер как приложение: иконка на экране «Домой», запуск на весь экран без адресной строки, push-уведомления на iPhone (Apple присылает их только установленным сайтам).

## Файлы

| Что                                | Где                                                                                                                                                                                            |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Манифест (`/manifest.webmanifest`) | `apps/web/src/app/manifest.ts` — название, иконки, `display: standalone`, ярлыки (долгое нажатие на иконку: Сообщения, Уведомления, Reels). Тексты на языке интерфейса (cookie `NEXT_LOCALE`). |
| Значок вкладки                     | `apps/web/src/app/icon.svg` (исходник иконки)                                                                                                                                                  |
| Иконка iPhone 180×180              | `apps/web/src/app/apple-icon.png` (квадрат без скруглений: iOS скругляет сама)                                                                                                                 |
| Иконки Android / Chrome            | `apps/web/public/icons/` — `icon-192.png`, `icon-512.png` (скруглённые), `maskable-512.png` (на весь квадрат, Android обрезает под свою форму), `icon-96.png` (ярлыки)                         |
| Метаданные, цвет статус-бара       | `apps/web/src/app/layout.tsx` (`metadata.appleWebApp`, `viewport`)                                                                                                                             |
| Сервис-воркер                      | `apps/web/public/sw.js` — push ([push.md](./push.md)) и страница офлайна                                                                                                                       |
| Страница офлайна                   | `apps/web/public/offline.html` — самодостаточная (свои стили, без шрифтов сайта), тема и язык как в приложении                                                                                 |
| Установка                          | `apps/web/src/features/pwa/`                                                                                                                                                                   |

Иконка — официальный значок Instagram (Wikimedia Commons, `Instagram_logo_2016.svg`), из него сделан `icon.svg` и все PNG. Для iPhone и `maskable` фон растянут на весь квадрат (системы скругляют сами), в `maskable` камера уменьшена до 86%, чтобы круглая маска Android её не резала.

**Телефон:** `maximumScale: 1` в `viewport` — iPhone не приближает страницу при фокусе на поле с текстом меньше 16px (щипком приближать по-прежнему можно).

## Поведение

- **Сервис-воркер** регистрируется на каждой странице (`features/pwa/install.ts`), а не только при включении push. Он кэширует только `offline.html` и иконку; всё остальное всегда из сети. Если страница не загрузилась без сети — показывается `offline.html`, при появлении сети она перезагружается сама.
- **Цвет статус-бара / панели браузера** — тег `theme-color` создаёт скрипт темы в `app/layout.tsx` до отрисовки (не React и не `viewport.themeColor`: они перерисовывают тег при переходах). Белый или `#0a0a0a`, при смене темы перекрашивает `applyTheme()`.
- **Отступы iPhone:** `viewport-fit=cover`, нижнее меню и отступ `<main>` выше на `env(safe-area-inset-bottom)`.
- **«Установить приложение»** в меню «Ещё» (боковое меню и верхняя панель телефона) показывается, только пока сайт не установлен:
  - Chrome / Edge (Android, компьютер): браузер присылает `beforeinstallprompt`, мы его придерживаем и по кнопке открываем системное окно установки;
  - iPhone / iPad: такого события нет, кнопка открывает лист с тремя шагами (Поделиться → На экран «Домой» → включить уведомления в настройках);
  - уже установлен (`display-mode: standalone`) или браузер не умеет: пункта нет.

## Push на iPhone

iOS 16.4+, сайт добавлен на экран «Домой» из Safari и открыт с иконки; уведомления включаются в настройках → Уведомления (запрос разрешения идёт после нажатия, как требует Apple). Сервер не меняется: те же ключи VAPID, адрес подписки Apple (`web.push.apple.com`) библиотека `web-push` обслуживает сама.
